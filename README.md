# Aryan Patel Portfolio

A simple static portfolio website with a homepage, navigation bar, welcome section, projects section, about section, and contact section.

## Run locally

From this folder:

```bash
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173
```

You can also open `index.html` directly in a browser, but the local server is the best way to preview the site.
